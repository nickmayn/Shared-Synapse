# Knowledge Taxonomy

Shared Synapse organizes durable knowledge into a small number of top-level categories under `knowledge/`.

## Categories

- `skills/` — Reusable workflows and execution patterns.
- `rules/` — Stable constraints, standards, and behavioral expectations.
- `tools/` — Tool definitions, API surfaces, and MCP-exposed integrations.
- `decisions/` — Architectural and design decisions with rationale.
- `concepts/` — High-level system concepts, overviews, and domain explanations.
- `designs/` — Theme, palette, and visual-direction documents for product surfaces.

## Notes

- Synapse bundles live in `synapses/` because they connect knowledge across categories rather than belonging to a single category.
- Legacy `systems/`, `playbooks/`, `context-packs/`, and `registry/` content has been folded into `concepts/`, `skills/`, `synapses/`, and `tools/`.
