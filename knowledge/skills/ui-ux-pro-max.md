# Skill: UI UX Pro Max

## When to Use
Use this skill for tasks that change how a product looks, feels, moves, or is interacted with.

## Focus Areas

1. Accessibility and interaction quality.
2. Style selection, typography, and color systems.
3. Responsive layout and navigation patterns.
4. Motion, form feedback, and information hierarchy.
5. Frontend code review for design-system consistency.

## Workflow

1. Start with accessibility, interaction safety, and mobile responsiveness.
2. Match the visual language to the product type instead of defaulting to generic UI patterns.
3. Use shared tokens, styling helpers, and service boundaries from the frontend rules.
4. Review the resulting UI for clarity, visual hierarchy, and user recovery paths.
